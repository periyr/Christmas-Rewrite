# Asset manifest (Person C)

All art except the room pictures is flat SVG in the shared palette. No text is drawn into any image: titles, clues and labels are interface text. File names match the constructors in `src/Domain.elm`, in kebab case.

**Origin and licence:** drawn for this project and free to use in this game.

- **Covers, diaries, damage, puppets, mystery books:** generated with Google Gemini from the team's prompt and palette, then checked and edited by the team (with help from Claude). `shadow-fox.svg` was redrawn by hand.
- **Player sprites (`player-*.svg`):** generated by `docs/asset-sources/make-characters.mjs`, a script written for the team with help from Claude. Edit the script and re-run it rather than editing the SVGs by hand: `node docs/asset-sources/make-characters.mjs` (or name one person, e.g. `walter`).
- **Room props (`room-*.svg`):** hand-written SVG for the team, with help from Claude.

### Player sprites (walking human characters)

Paper-cutout people, separate from the shadow puppets. Every frame:

- `viewBox 0 0 96 160`, transparent background apart from a faint ground shadow (ink at 18% opacity, centred on x = 48, y = 152).
- **Anchor:** shoe soles exactly on **y = 152** (the outline adds 0.75 below). Feet are centred near **x = 48**: ankles at 45 and 50 standing, 35 and 61 mid-stride. Position a sprite by its anchor point (48, 152), e.g. `transform-origin: 50% 95%`.
- **Faces right.** Flip horizontally for walking left (`transform: scaleX(-1)`); the anchor stays put, because x = 48 is the centre.
- **Identical scale and fixed body:** head, neck, torso and hips are the same bytes in all three frames. Only arms and legs move, so nothing jumps when frames change.
- **Scale:** about 1 unit = 1.1 cm (a 1.75 m adult). The room props below use the same scale.
- **Frames:** `idle` stands. `walk-1` has the near leg forward and far arm forward. `walk-2` is the opposite. A cycle of `walk-1 → walk-2` (around 4–6 frames a second) reads as walking; return to `idle` when the character stops.
